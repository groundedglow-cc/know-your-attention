# 儿童翻牌配对游戏 PRD：翻翻找朋友

## 产品目标

开发一个面向 4 岁儿童的翻牌配对网页游戏，支持手机、iPad 和电脑。孩子通过翻开卡片寻找相同图片，体验观察、记忆、轮流和完成任务的乐趣；无需识字即可操作，老人可轻松陪玩。

首版不需要账号、联网对战、排行榜、倒计时、广告或付费系统。

## 规则与难度

每种图片出现两次，随机背面朝上排列。玩家每回合翻两张不同卡片：相同则保持正面并完成配对；不同则完整展示一小段时间后翻回。全部配对即完成。

默认为「自己找朋友」，动物主题、3 对／6 张。难度由孩子或家长主动选择：小小挑战 3 对／6 张、再多一点 4 对／8 张、大大挑战 6 对／12 张。不按胜率自动升级；默认模式可由家人约定轮流翻两张，不显示输赢排名。

## 页面与交互

- 首页：游戏名、示例卡、大号「开始玩」、主题、难度、家长设置和始终可见的声音开关；记住最近选择与声音偏好。
- 游戏页：返回、图形化星星进度、声音开关、主卡片网格和「看一眼」提示；不显示计时、失误或评分。
- 完成后保留整个棋盘，播放温和庆祝，显示「都找到啦！」及「再玩一次」「换一组」，不自动开局也不以弹窗遮棋盘。
- 卡片整张可点，翻牌约 200–300ms；按下缩小，移出再松开取消。已翻或已配对的牌无效。
- 成功时两张牌轻弹、出现小星星、柔和音效、保留原位并以勾与边框标示；失败展示默认 1.8 秒后翻回，无红叉、震动或警报。
- 比较期间禁止第三张牌；同一张牌不可算两次；快速点击和多指触摸不能破坏状态。
- 「看一眼」只在没有待比较牌时可用：显示所有未匹配卡约 2 秒，期间锁定操作；不限次数、不扣分，已配对牌保持正面。

## 首次教学

首次可展示且可重播、可跳过的 2 对／4 张互动演示：呼吸动画引导第一张，再引导相同的第二张，成功后展示靠近与亮起效果，并以图示表达「翻两张，找一样的」。正式游戏随机排列，教学位置固定。

## 图片、主题与导入

内置统一卡通风格主题，每种至少六张不同图片：小动物（猫、狗、兔子、大象、熊猫、企鹅）、交通工具（汽车、公交车、火车、飞机、轮船、挖掘机）、水果（苹果、香蕉、草莓、葡萄、西瓜、橙子）。单个主体应清晰、颜色轮廓差异明显、无文字水印复杂背景，主体约占 70%–85%。

家长可建立本地自定义主题：选择 3–12 张 JPEG、PNG 或 WebP，调整大尺寸裁剪预览，命名并保存；按难度抽取不同图片，数量不足时明确提示或选择低难度，不能复用一张图片当不同身份。图片仅本地处理，最长边压缩至约 512px，以 IndexedDB 保存；支持删除确认、存储/解码失败等可理解反馈。不得内置未经授权的动画截图、抓取平台图片或热链。素材来源与授权说明列在项目素材清单，不在儿童页面展示。

## 视觉、声音与无障碍

使用温暖绘本风：浅奶油背景、圆角厚卡、轻阴影、统一且不泄露身份的卡背（叶子／星星／脚印）、宽间距；主题可改变卡背颜色但固定提示按钮与进度位置。状态不仅靠颜色表达。

默认音效开、背景音乐关；翻牌为轻柔「啵」声，成功为短促悦耳音，通关为 1–2 秒小旋律。声音开关立即停止声音并记住偏好；首次手势后初始化 Web Audio，失败不影响游戏。尊重 `prefers-reduced-motion`，不闪屏或剧烈摇晃，动画不是状态转换依据。

支持手机、iPad、桌面和横竖屏；6 张为 3×2，8 张窄屏 2×4／宽屏 4×2，12 张窄屏 3×4／宽屏 4×3。旋转及 resize 不能重置对局。卡片至少 80×80 CSS px，普通按钮至少 56×56 px；允许滚动、适配安全区，不依赖 hover、不禁止缩放。支持焦点、Enter/Space；卡背 aria 名称不泄露对象，翻开和配对后读出状态，并用 aria-live 报告结果。

## 技术与验收

沿用现有静态游戏目录。游戏状态、牌组生成、洗牌与 UI 分离；以稳定 `cardId` 标识牌、`pairId` 标识关系，Fisher–Yates 洗牌，同一对共享图片数据。重开、切换主题、返回首页时清理定时器；后台暂停待翻回，恢复后补足观察时间；预加载素材后才可玩。

必须验证：每图恰好两次且不同 pairId 视觉不同；不能自己配自己、比较时不能翻第三张、成功牌不移动；失败观察时间完整；最后一对只触发一次完成事件；快速／多指点击与旧定时器不会破坏新局；提示正确恢复；旋转不重置；静音、后台、音频失败仍可完整游戏；导入失败或数量不足有明确处理；孩子看过一次示范即可完成翻牌及再玩一次。

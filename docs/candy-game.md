# 小小游戏室 / 奇妙糖果机

纯 HTML、CSS、ES modules，无第三方运行依赖。Node.js 20+。

```sh
npm run dev:candy
# 如默认 5173 端口已占用：
PORT=5188 npm run dev:candy
npm test
npm run build:candy
```

入口 `/game/candy`（有无尾部斜线均可），首页 `/` 是可扩展的游戏目录。
`dist-candy/` 为静态构建产物，可交给静态网站服务器托管。
同一 Wi-Fi 下的 Pad 可访问 `http://电脑局域网IP:5188/game/candy/`，需要系统允许本地服务网络访问。

## 当前实现

- 根据提供的册子第 5 页逐格录入全部 4 个 3×3 关卡，固定起终点方向和 STOP。
- 鼠标、触摸、触控笔拖拽；点选放置；旋转；回收；撤销；重新开始。
- 逐步提示：先提示位置，再提示管型和方向；存在冲突时提示单张待调整卡片。
- 严格检查填满、相邻端口匹配、边界、STOP 和从起点到终点的完整线路。
- 金边和纸屑成功效果，支持减少动态效果偏好。
- 本地保存每关进度与完成记录，首次玩法引导。
- 电脑双栏布局，窄屏纵向布局，不依赖外部字体、图片或网络服务。

## 扩展关卡

编辑 `public/game/candy/levels.js`。格子按从左到右、从上到下编号，从 0 开始；方向 0 上、1 右、2 下、3 左。

```js
{ id: 5, name: '关卡名称', size: 4, stops: [/* 固定障碍索引 */],
  start: { index: 0, direction: 1 }, end: { index: 15, direction: 3 } }
```

棋盘渲染和求解器使用 `size`，可承载 4×4 和 5×5；目前没有录入未提供的布局。大棋盘需根据新增题目验证求解性能。
当前四关均为单色糖果管道，因此工具箱提供蓝色直管、弯管和交叉管；按材料清单限制为 10、10、5 张。交叉管按两条独立直行通道处理。材料中的黄/蓝双色及混合双弯卡需在后续双色题目到来时扩展颜色通道模型，不能仅新增布局即支持。

## 验证

`node --test` 验证四关可解、固定布局、缺卡不能完成、错误方向不能完成、提示定位、边界及 STOP 冲突。浏览器人工检查的范围见交付说明；自动测试不替代真实 iPad 触摸测试。

当前仓库初始无提交、无原应用代码，只有未跟踪的 package-lock.json；本实现没有迁移任何已有业务。

## 低龄与移动端交互

- 图画玩法教程、笑脸回收盒、糖果小精灵提示。提示依次给出位置和半透明管道示范，仍保留简短文字便于家长辅助。
- 点击棋盘管道顺时针旋转 90°；旋转可以撤销。触摸拖拽的预览向手指上方偏移，减少遮挡。
- 完成关卡显示奖章及“已完成”。启动时进入首个未完成关卡；全部完成则回到第一关。重玩会清除当前完成状态，撤销恢复已解棋盘时恢复奖章。
- 左右箭头直接切换相邻关卡；关卡栏支持触摸原生横向滑动、鼠标拖动浏览、点击选择与键盘方向键。
- 手机压缩装饰区域，棋盘尽量占满宽度，管道区与回收盒并排；短屏自然滚动，不通过把卡片缩得过小来强塞一屏。Pad 横屏高度较低时会进一步压缩顶部导航、关卡栏、间距和工具区，把可见空间优先留给完整棋盘与可拖拽卡片。

册子后续图片已整理为 `public/game/candy/booklet-layouts.js`，并已生成到正式关卡列表中（第 9–39 题，3×3、4×4 和 5×5）。当前版本保留了已验证可解的 STOP 固定障碍组合；人物、糖果罐和预置管道先作为布局元数据保留，后续扩展颜色通道和多端点规则时可以继续细化，不影响当前关卡的拖拽、旋转和通关流程。

4×4 浏览器布局测试（独立存档，不进入正式关卡列表，也不打包进 dist）：

```sh
node scripts/preview-fixture.mjs
# 打开 /tests/fixtures/candy-4x4.html
```

## 交互音效

旋转、放置、成功回收、通关各有短音效；点击固定卡片、不可用按钮或无效放置时播放柔和提示音。右上角 🔊 / 🔇 开关可以静音并保存偏好。音效用 Web Audio 本地合成，仅在操作后播放，无需音频下载；浏览器不支持或限制音频时，游戏仍正常运行。

游戏现已集成回原有 Vite 应用：`npm run dev` 启动完整项目，`npm run build` 构建原应用及游戏，游戏资源由 `public/game/` 原样拷贝到 `dist/game/`。独立预览与构建可使用上面的 `:candy` 脚本。根首页保留原有业务，游戏目录页为 `/game/`。
